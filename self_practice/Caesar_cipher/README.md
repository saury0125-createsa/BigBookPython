# Caesar Cipher(English)

A simple command-line Caesar Cipher tool written in Python.

You can encrypt or decrypt messages by shifting letters by a given key (0–25).

## Features

- Encrypt / Decrypt text
- Supports uppercase & lowercase input (automatically converts to uppercase)
- Non-letter characters (spaces, punctuation, numbers) are preserved
- Key range: 0 ~ 25

## How to Run
```bash
python CaesarCipher_first.py
